# Kredit Foto Produk

Foto produk di `public/images/products/` (24 file, dipakai oleh `src/data/products.js`) diambil dari
kumpulan foto produk fashion yang disediakan pengguna proyek ini (disimpan di luar repo karena
ukurannya besar).

> **Catatan:** set foto pertama (bersumber dari Wikimedia Commons / rawpixel / StockSnap, berlisensi CC0
> & CC BY) yang dipakai di tahap awal proyek sudah dihapus dan digantikan seluruhnya oleh set ini, supaya
> gaya foto di seluruh katalog konsisten (latar putih, foto studio).

- Folder sumbernya tidak menyertakan file metadata/lisensi per foto (tidak ada nama fotografer atau sumber per gambar).
- Sebagian foto asal berasal dari katalog e-commerce multi-brand dan menampilkan produk bermerek. Untuk menghindari klaim identitas brand, **setiap foto yang dipakai di sini diberi nama produk generik buatan sendiri** (bukan nama brand aslinya) dan foto dengan logo/motif brand yang jelas terlihat (mis. teks merek, motif garis signature, hardware berlogo) sengaja tidak dipilih — sudah diperiksa satu per satu.
- Tim disarankan mengecek ulang sumber dataset ini sebelum dipakai di luar konteks tugas kuliah (demo/skripsi/portofolio publik jangka panjang), karena status lisensi foto asli tidak dapat diverifikasi dari file yang tersedia.
